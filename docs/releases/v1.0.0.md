# EME APP 1.0.0

The first official version. From now on every version is built and published by GitHub, with its own release notes. Below is everything that changed since 0.16.

## New
- N0UK tab: the N0UK WSJT EME chat (144 MHz), read only, with the messages, the stations that are QRV and a Chat CQ table. (#40)
- New tab layout: Moon, Deg, HB9Q, N0UK, Live CQ. Chat CQ is now a sub-page of HB9Q, next to Messages and QRV. (#39, #41)
- Chat CQ shows the CQ calls of the last 60 minutes, the same period as Live CQ and the world map. (#38)
- The version number is shown next to the title. (#45)

## Fixed
- Chat CQ recognises Q65 with a 120 s or 300 s period; before, the mode showed "?" and the Hz column could be wrong. (#16)
- A CQ posted just before midnight UTC no longer drops out of Chat CQ. (#17)
- The system back button in Settings returns to the tabs instead of closing the app. (#19)
- Saving the HB9Q login a second time without retyping the password keeps that password. (#21)
- A failed HB9Q login no longer retries on every refresh; the app waits before it tries again. (#22)
- Changing the HB9Q login no longer gets stuck on "login form not found" until the app is restarted. (#23)
- An HB9Q error message only shows on the band it belongs to. (#26)
- An incomplete answer from HB9Q shows an error instead of an empty chat. (#29)

## Under the hood
- One User-Agent with the app version for all requests, and smaller code clean-ups. (#20, #24, #30, #31)

## Updating
- Installs over 0.16, 0.17 and 1.0.0-test1; settings and HB9Q login are kept.
